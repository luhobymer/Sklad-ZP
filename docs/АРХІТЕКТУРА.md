## 🗄️ База даних (SQLite)

### Схема бази даних

```sql
-- Таблиця запчастин
CREATE TABLE parts (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  article TEXT,
  manufacturer TEXT,
  category_id TEXT,
  quantity INTEGER DEFAULT 0,
  price REAL DEFAULT 0,
  condition TEXT CHECK(condition IN ('нова', 'б/у')) DEFAULT 'нова',
  location TEXT,
  notes TEXT,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (category_id) REFERENCES categories(id)
);

-- Таблиця категорій
CREATE TABLE categories (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  icon TEXT,
  color TEXT,
  parent_id TEXT,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (parent_id) REFERENCES categories(id)
);

-- Таблиця фотографій
CREATE TABLE photos (
  id TEXT PRIMARY KEY,
  part_id TEXT NOT NULL,
  file_path TEXT NOT NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (part_id) REFERENCES parts(id)
);

-- Таблиця налаштувань
CREATE TABLE settings (
  key TEXT PRIMARY KEY,
  value TEXT,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### Індекси для продуктивності
```sql
CREATE INDEX idx_parts_category ON parts(category_id);
CREATE INDEX idx_parts_name ON parts(name);
CREATE INDEX idx_parts_article ON parts(article);
CREATE INDEX idx_parts_condition ON parts(condition);
CREATE INDEX idx_photos_part ON photos(part_id);
CREATE INDEX idx_categories_parent ON categories(parent_id);
```

## 🔄 Потік даних

### Архітектура компонентів
```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   UI Component  │───▶│  Redux Action   │───▶│  Redux Reducer  │
└─────────────────┘    └─────────────────┘    └─────────────────┘
         ▲                                              │
         │                                              ▼
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│  React Hook     │◀───│   Redux Store   │◀───│   Database      │
└─────────────────┘    └─────────────────┘    └─────────────────┘
```

### Життєвий цикл операції
1. **UI Event** - користувач взаємодіє з інтерфейсом
2. **Action Dispatch** - відправка дії до Redux
3. **Middleware** - обробка асинхронних операцій
4. **Database Operation** - робота з SQLite
5. **State Update** - оновлення стану
6. **UI Re-render** - перерендер інтерфейсу
