# Інструкція для встановлення додатку "Склад Автозапчастин"

## Підготовка до встановлення

1. **Встановіть Node.js** (рекомендовано версію LTS):
   - [Завантажити Node.js](https://nodejs.org/)
2. **Встановіть Yarn або npm** (за бажанням):
   - Yarn: `npm install -g yarn`
3. **Встановіть Android Studio** (для емулятора та SDK) або Xcode (для macOS/iOS)
4. **Встановіть залежності проекту:**
   ```bash
   cd c:\Users\SANYA\Desktop\Sklad-ZP
   yarn install
   # або
   npm install
   ```
5. **Налаштуйте змінні середовища** у файлі `.env` (див. README.md та SETUP-GOOGLE-DRIVE.md)

## Запуск додатку на Android

1. **Запустіть емулятор або підключіть пристрій**
2. **Запустіть Metro bundler:**
   ```bash
   yarn start
   # або
   npm start
   ```
3. **Запустіть додаток на Android:**
   ```bash
   npx react-native run-android
   # або для релізної збірки
   npx react-native run-android --variant=release
   ```

## Запуск додатку на iOS (тільки для macOS)

1. **Встановіть CocoaPods:**
   ```bash
   sudo gem install cocoapods
   ```
2. **Встановіть pod-залежності:**
   ```bash
   cd ios && pod install && cd ..
   ```
3. **Запустіть додаток на iOS:**
   ```bash
   npx react-native run-ios
   # або для релізної збірки
   npx react-native run-ios --configuration Release
   ```

## Важливі примітки

1. **Дозволи додатку:**
   - При першому запуску додаток запитає дозволи на доступ до камери, сховища, фото та Google Drive (для резервного копіювання)
   - Необхідно надати ці дозволи для правильної роботи додатку
2. **Розпізнавання тексту:**
   - Для розпізнавання тексту з фотографій використовується Google Cloud Vision API
   - Для коректної роботи потрібне підключення до інтернету
3. **Оновлення додатку:**
   - Для отримання оновлень оновіть репозиторій та перевстановіть залежності
   - Для Android/iOS створіть нову збірку та встановіть її на пристрій

## Усунення несправностей

1. **Проблеми з камерою або файлами:**
   - Перевірте, чи надано всі необхідні дозволи
   - Перезапустіть додаток
2. **Проблеми з розпізнаванням тексту:**
   - Переконайтеся, що є підключення до інтернету
   - Спробуйте зробити фото з кращим освітленням
   - Переконайтеся, що текст на фото чіткий і добре видимий
3. **Загальні проблеми:**
   - Перезапустіть додаток
   - Перевірте наявність оновлень
   - Видаліть і встановіть додаток заново
