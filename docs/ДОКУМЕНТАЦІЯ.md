## 🔍 Новий функціонал

### Пошук аналогів запчастин

- **Автоматичний пошук** - система знаходить аналоги на основі характеристик
- **Оцінка сумісності** - показує рівень відповідності аналогів
- **Фільтрація за наявністю** - показує тільки доступні на складі аналоги
- **Детальна інформація** - причини відповідності та рекомендації

### Пошук за автомобілями

- **Перегляд сумісних авто** - список автомобілів для кожної запчастини
- **Фільтрація за моделлю** - швидкий пошук запчастин для конкретного авто
- **Інтерактивний інтерфейс** - зручні модальні вікна та підменю
- **Двосторонній пошук** - від запчастини до авто і навпаки

### Покращений інтерфейс

- **Підменю в деталях** - швидкий доступ до аналогів та сумісних авто
- **Модальні вікна** - зручний перегляд додаткової інформації
- **Кнопка "Авто"** - швидкий доступ до пошуку за автомобілями
- **Інтуїтивна навігація** - логічні переходи між екранами

## 🏗️ Архітектура проекту

### Основні директорії

```
src/
├── components/     # React компоненти
│   ├── AnalogSearchView.tsx      # Пошук аналогів на складі
│   ├── CarCompatibilityView.tsx  # Перегляд сумісних автомобілів
│   ├── CarSearchView.tsx         # Пошук запчастин за автомобілями
│   ├── PartDetails.tsx           # Деталі запчастини (оновлено)
│   └── PartsList.tsx             # Список запчастин (оновлено)
├── screens/        # Екрани додатку
├── services/       # Бізнес-логіка та API
├── utils/          # Допоміжні функції
├── types/          # TypeScript типи
└── navigation/     # Навігація
```

### Ключові технології

- **React Native**
- **TypeScript** для типізації
- **React Navigation** для навігації
- **AsyncStorage** для локального зберігання
- **Google Drive API** для синхронізації
- **React Native Camera** для сканування

## 📝 Корисні команди

### Розробка

```bash
# Запуск Metro bundler
npm start

# Запуск на Android
npm run android

# Перевірка TypeScript
npx tsc --noEmit

# Очищення кешу
npm run clean
```

### Збірка

```bash
# Debug збірка
cd android && ./gradlew assembleDebug

# Release збірка
cd android && ./gradlew assembleRelease
```
